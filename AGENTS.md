# Working on Budge

Read PRODUCT.md before product or interface changes.

Budge is intended for people beyond its original household. Apply the reusable-product requirements in PRODUCT.md to every feature, not only new mortgage tools. Derive names, providers, dates, schedules, account identities and ownership from user data or configuration. Keep account-specific setup and migrations scoped to that account.

Respect current data-model limitations without exposing internal owner keys as personal assumptions or claiming unsupported household arrangements. Make calculation assumptions explicit and preserve existing user data through changes.
